01 About me

I learn
by building.

I'm Dilashma, and I enjoy taking an idea from a blank file to something people can click, use, and hopefully enjoy.

My foundation started with Java and Python — object-oriented programming, data structures, and problem solving. Since then I've moved into full-stack development: I built DigitalMenu with a React front end, a Node.js and PostgreSQL backend, and a Kotlin Android app. I've also worked with R on real public datasets, cleaning and joining data to find patterns and build a simple recommendation model.

I care about clean structure, interfaces that feel obvious, and code that another person can read. Right now I'm sharpening my backend and mobile skills, practising data structures and algorithms, and looking for an internship where I can learn from a team that ships real products.
